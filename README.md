The AI sections are explicitly documented as simulated local-LLM first drafts. They demonstrate the required verify-first workflow without claiming that Ollama was actually executed here. To reproduce the exercise locally, install Ollama, run ollama pull mistral, submit the source letter and clinic blurb, save the raw responses, and compare them with the curated files in this folder.

Repository setup

Create a repository named ba-training-portfolio, place this folder at assignment-01/, then commit and push it to GitHub or GitLab. The public repository link must be added by the student after the repository is created.
